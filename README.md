# 발자국 한글 · Kiwi Footprints (데모)

날지 못하는 키위들이 해변으로 걸어 나와 발자국으로 한글을 쓰고, 파도가 지웁니다.

- 보기: https://khuvdmingu.github.io/kiwi-footprints-demo/
- 이 저장소는 화면을 보여 주기 위한 빌드 사본입니다. 개발 기록은 비공개 저장소에 있습니다.
- 배경·키위·갈매기 그림은 AI 이미지 생성(Higgsfield)으로 만들었습니다.
- WebGL2가 되는 최신 브라우저에서 열어 주세요. 휴대폰 세로 화면은 세로 전용 그림으로 바뀝니다.
